# OneCX Service Smart Redirect

## [](#%5Fconfiguration)Configuration

 Configuration property fixed at build time - All other configuration properties are overridable at runtime

| Configuration property                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Type               | Default  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | -------- |
| [onecx.redirect.host-forward-rules."host-forward-rules".host-pattern](#onecx-service-redirect%5Fonecx-redirect-host-forward-rules-host-forward-rules-host-pattern) Regex matched against the incoming request host. Environment variable: ONECX\_REDIRECT\_HOST\_FORWARD\_RULES\_\_HOST\_FORWARD\_RULES\_\_HOST\_PATTERN                                                                                                                                                                                                                                                                                      | string             | required |
| [onecx.redirect.host-forward-rules."host-forward-rules".host-replace-pattern](#onecx-service-redirect%5Fonecx-redirect-host-forward-rules-host-forward-rules-host-replace-pattern) Replacement pattern for the host regex match. Supports capture groups: use ($groupName) or $1, $2, etc. for group replacement. Example: if hostPattern is "(.\*)\\\\.old-domain\\\\.com" and hostReplacePattern is "$1.new-domain.com", a request to "api.old-domain.com" redirects to "api.new-domain.com". Environment variable: ONECX\_REDIRECT\_HOST\_FORWARD\_RULES\_\_HOST\_FORWARD\_RULES\_\_HOST\_REPLACE\_PATTERN | string             | required |
| [onecx.redirect.host-forward-rules."host-forward-rules".protocol-replace-pattern](#onecx-service-redirect%5Fonecx-redirect-host-forward-rules-host-forward-rules-protocol-replace-pattern) Optional replacement pattern for the target protocol (e.g. "https"). If not provided, the original request protocol is used. Environment variable: ONECX\_REDIRECT\_HOST\_FORWARD\_RULES\_\_HOST\_FORWARD\_RULES\_\_PROTOCOL\_REPLACE\_PATTERN                                                                                                                                                                     | string             |          |
| [onecx.redirect.rules.mode](#onecx-service-redirect%5Fonecx-redirect-rules-mode) combined: host forwarding and path rewrite are applied in one flow. separate: host forwarding and path rewrite are evaluated independently. Environment variable: ONECX\_REDIRECT\_RULES\_MODE                                                                                                                                                                                                                                                                                                                               | combined, separate | combined |
| [onecx.redirect.rules.redirect-wait-seconds](#onecx-service-redirect%5Fonecx-redirect-rules-redirect-wait-seconds) Redirect wait time in seconds. Environment variable: ONECX\_REDIRECT\_RULES\_REDIRECT\_WAIT\_SECONDS                                                                                                                                                                                                                                                                                                                                                                                       | int                | 10       |
| [onecx.redirect.url-rewrite-rules."url-rewrite-rules".pattern](#onecx-service-redirect%5Fonecx-redirect-url-rewrite-rules-url-rewrite-rules-pattern) Regex pattern tested against window.location.href (including fragment) in the browser. Environment variable: ONECX\_REDIRECT\_URL\_REWRITE\_RULES\_\_URL\_REWRITE\_RULES\_\_PATTERN                                                                                                                                                                                                                                                                      | string             | required |
| [onecx.redirect.url-rewrite-rules."url-rewrite-rules".replace-pattern](#onecx-service-redirect%5Fonecx-redirect-url-rewrite-rules-url-rewrite-rules-replace-pattern) Replace-pattern to rewrite the URL. Use ($groupName) to reference named capture groups. Environment variable: ONECX\_REDIRECT\_URL\_REWRITE\_RULES\_\_URL\_REWRITE\_RULES\_\_REPLACE\_PATTERN                                                                                                                                                                                                                                            | string             | required |
| [onecx.redirect.custom-redirect-template-path](#onecx-service-redirect%5Fonecx-redirect-custom-redirect-template-path) File path to custom redirect template Environment variable: ONECX\_REDIRECT\_CUSTOM\_REDIRECT\_TEMPLATE\_PATH                                                                                                                                                                                                                                                                                                                                                                          | string             |          |
| [onecx.redirect.bundled-redirect-template-name](#onecx-service-redirect%5Fonecx-redirect-bundled-redirect-template-name) Bundled redirect template name loaded from classpath templates. Example: redirectWaitTemplate.html. Environment variable: ONECX\_REDIRECT\_BUNDLED\_REDIRECT\_TEMPLATE\_NAME                                                                                                                                                                                                                                                                                                         | string             |          |
| [onecx.redirect.custom-fallback-template-path](#onecx-service-redirect%5Fonecx-redirect-custom-fallback-template-path) File path to custom fallback template Environment variable: ONECX\_REDIRECT\_CUSTOM\_FALLBACK\_TEMPLATE\_PATH                                                                                                                                                                                                                                                                                                                                                                          | string             |          |

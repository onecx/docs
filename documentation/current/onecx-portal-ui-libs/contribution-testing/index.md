# Contribution &amp; Testing

This page describes how to verify a change to the OneCX UI libraries before it is merged. Choose the tier by the **scope of the change** — how far the change has to travel to be exercised.

## [](#which-tier)Which tier is your change?

* [Local-only](local-only.html) — the change is fully exercised by the library’s own unit tests and Storybook.
* [Integration](integration.html) — the source change is in a library and it must be verified inside the OneCX Shell together with one or more local applications.
* [Application-only](application-only.html) — the source change is confined to a single OneCX application.

# Migrating an Existing App

This section covers bringing an existing Angular application to OneCX. Pick the branch that matches your starting point.

## [](#start-from-vanilla)Start from a vanilla app

Use this branch when the application is not yet a OneCX app. Pick the guide that matches the OneCX platform library version you are integrating against.

* [Migrate a vanilla Angular app to OneCX](vanilla-to-onecx-angular.html) — walks the app to the current OneCX end-state (v8 baseline) by cross-linking into the setup pages rather than restating their steps.
* [Migrate vanilla Angular apps to OneCX (legacy guide)](../angular/app-to-onecx.html) — use this guide first if the app is still on an older Angular version, then follow the version-specific upgrade guides below to reach the current OneCX version.

## [](#upgrade-an-existing-onecx-app)Upgrade an existing OneCX app

Use this branch when the application is already a OneCX app and needs to be upgraded across OneCX platform library versions. Follow the guide for the version you are moving to:

* [Upgrade to Angular 19](../../onecx-portal-ui-libs/migrations/angular-19/index.html)
* [Upgrade to Angular 20](../../onecx-portal-ui-libs/migrations/angular-20/index.html)
* [Upgrade to Angular 21](../../onecx-portal-ui-libs/migrations/angular-21/index.html)

# Preparation

Work through these steps before digging into a specific error. They set up the app and the debugging environment so the root cause of an issue is easier to identify.

## [](#ui-compatibility)UI compatibility

Make sure that the app follows the required OneCX application setup described in [Required Setup](../setup/required/index.html), especially the platform/package compatibility, package sharing, and module federation configuration steps.

## [](#improve-debugging-experience)Improve the debugging experience

To understand the root cause of issues, it is recommended to enable source maps in the application and shell during development. For more information on how to enable source maps, see [Enable source maps guide](../ui-additional/enable-source-maps.html).

# OneCX Documentation

Welcome to the OneCX documentation hub for contributors and users. This page is your entry point to the guides, conventions, and tooling used to write and publish OneCX documentation.

## [](#purpose)Purpose

The goal of this guide is to keep documentation simple, consistent and easy to maintain across the OneCX ecosystem. We author content in [AsciiDoc](https://docs.asciidoctor.org/asciidoc/latest/) and publish sites using [Antora](https://docs.antora.org/antora/latest/).

## [](#audience)Audience

* Developers and technical writers authoring or reviewing docs
* Product owners wanting an overview of available guides
* Contributors integrating new modules or updating existing content

## [](#authoring-guidelines)Authoring Guidelines

* Follow the general guidelines in [OneCX Docs: Guidelines](guidelines.html).
* For writing style guidelines, see [OneCX Docs: Writing Style](writing%5Fstyle.html).
* For formatting and conventions, see [OneCX Docs: Formatting](formatting.html).

## [](#getting-started)Getting Started

To set up your local environment for writing and previewing OneCX documentation, follow the instructions in [OneCX Docs: Local Setup](setup.html).

## [](#reference)Reference

See the [OneCX Local Environment](../onecx-local-env/index.html) \- it is our reference implementation for structure, style and conventions.

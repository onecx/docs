= Release Overview
:idprefix:
:idseparator: -

This page gives a high-level view of what is coming for the OneCX UI libraries and OneCX Shell in the near term. It is a planning overview — not a step-by-step guide. For the details of a specific upgrade, follow the links into the individual migration guides.

[#onecx-libs]
== OneCX UI Libraries

The OneCX UI libraries are moving to a fully open-source stack in two stages. The two stages target different Angular versions and are delivered separately, so we describe them separately below.

[#onecx-libs-angular-22]
=== Angular 22 — Optimus UI

With **Angular 22** support, the `@onecx/*` UI libraries are released as **version 9.0.0** and change the component library they are built on: from **PrimeNG** to **Optimus UI**. Optimus UI is an open-source, community-maintained fork of PrimeNG that keeps the PrimeNG API. Because PrimeNG has stopped being open source, moving to Optimus UI lets OneCX keep its own libraries fully open source while staying close to the PrimeNG APIs many applications already use.

Key points:

* **Optimus UI replaces PrimeNG under the hood.** The public PrimeNG-style component APIs are preserved, so applications that use them continue to work.
* **A few names change.** To reflect the new dependency, a couple of public entry points are renamed (for example the theme entry point and the PrimeNG wrapper module). These are called out as breaking changes in the version 9.0.0 release notes.
* **A tooling update is required.** Consuming applications need to bump to the new OneCX library version and the Angular 22 toolchain (the migration guide lists the versions to check).
* **OneCX Shell** adds an Angular 22 preloader so that Angular 22 applications load correctly inside the Shell.

For the full, step-by-step guide to migrating an application to Angular 22 with the Optimus UI change, see the xref:documentation:onecx-portal-ui-libs:migrations/angular-22/migration-plan.adoc[Angular 22 migration guide].

[#onecx-libs-angular-23]
=== Angular 23 — Angular Material + Tailwind CSS

With **Angular 23** support, the OneCX UI libraries take the next step: the OneCX components themselves (the `@onecx/*` accelerator components) are rebuilt on **Angular Material**, styled with **Tailwind CSS** — a library maintained by the Angular team itself.

Key points:

* **Optimus UI support is retained.** Applications that rely on the PrimeNG-style API are not forced to change. The components that need to *configure* PrimeNG/Optimus UI continue to support Optimus UI.
* **Accelerator components move to Angular Material.** The `@onecx/*` accelerator components are rebuilt on Angular Material + Tailwind CSS. The goal is to keep their public APIs stable where possible; any intentional changes are documented.
* **This is a larger, multi-stage effort.** Because it replaces every PrimeNG-backed component one at a time, it takes longer than the Angular 22 change. As a rough guide: expect it to span roughly a couple of release cycles, with detailed, component-level guidance published here as each area is finalized. Exact timing will be refined as the work proceeds.

The Angular 23 migration guide and its step-by-step sections are being published as the work is finalized.
